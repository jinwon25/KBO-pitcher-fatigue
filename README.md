# KBO 선발 투수 피로도 지수로 설계하는 최적의 투수 교체 가이드라인

> 🏆 **DArt-B 제4회 학술제 대상 수상작** — 2025 시즌 KBO 선발 투수 등판 데이터를 수집하여 피로 누적 지표를 결합한 **0~100 스케일 피로도 지수(Fatigue Score)** 를 설계하고, Decision Tree·GridSearchCV로 도출한 **교체 임계값 72.6**과 두 투수 GS 회귀선의 교차점으로 정의한 **역전점**까지 Streamlit 앱으로 패키징한 데이터 분석 프로젝트입니다. 피로도 지수와 WHIP(출루 허용률) 사이 **r = 0.76**의 강한 상관을 확인하여, 감독의 직관에 의존하던 투수 교체 결정에 정량적 가이드라인을 제시합니다.

## 2. 분석 요약 (Key Findings)

- **0~100 스케일 피로도 지수(Fatigue Score) 설계** — 4개 피처(NP/IP · 3경기 변화구 구사율 · 혹사 정도 · 누적 연투 일수)를 RandomForest · XGBoost · LightGBM 앙상블로 FIP 예측 후 SHAP 가중치를 곱해 산출.
- **피로도 ↔ 투수 성과 상관 입증**: WHIP(출루 허용률) **r = 0.76** (R² = 0.58), ERA r = 0.55 (R² = 0.30), FIP r = 0.50 (R² = 0.25), GS **r = −0.50** (R² = 0.25).
- **교체 임계값 = 피로도 지수 72.6** — Decision Tree + GridSearchCV로 회복 여부(휴식일 5일 이상)를 타깃 학습. 분포 상위 약 **20%** 구간에 해당하며 초과 시 교체·휴식 자동 권고.
- **투수 역전점 시뮬레이터** — 외부 환경·기량·신체 변수를 다중 회귀에 투입, 두 투수 A·B의 GS 회귀선 교차점을 역전점으로 정의. Streamlit 앱에서 기준 날짜의 최근 30일 피로도 흐름과 역전점을 비교해 *"A 기용 권장 / B 기용 고려"* 메시지를 자동 출력.

## 3. 배경 및 목적

세이버메트릭스의 등장으로 야구 운용의 과학화는 가속되었으나, **투수 교체 결정만큼은 여전히 감독의 감과 직관에 의존**한다는 비판이 끊이지 않습니다. 한국 야구의 얇은 선수층은 몇몇 핵심 투수에게 의존하는 운용을 강요하고, 이는 피로 누적과 성적 저하·부상으로 이어집니다.

본 프로젝트는 다음 세 가지 질문에 답하는 것을 목표로 합니다.

1. 투수 피로도에 영향을 미치는 변수는 무엇인가?
2. 피로 누적은 어떤 맥락에서 자주 발생하는가?
3. 피로도를 수치화할 때 핵심적으로 작용하는 변수는 무엇인가?

## 5. 분석 흐름

### 5.1 데이터 수집 (크롤링)

MYKBO·스탯티즈·KBO 공식 사이트에서 BeautifulSoup·Selenium으로 경기별·시즌별 데이터를 수집하고, 기상청 정보와 결합하여 체감온도를 산출합니다.

- `crawlers/스탯티즈_크롤링.ipynb`, `투수_크롤링.py`, `타자_크롤링.py`, `바이오_크롤링.py`, `소속팀_크롤링.py`, `데이터_병합.ipynb`

### 5.2 가설 검정 (피처 선별)

수집된 변수 중 모델 입력에 사용할 피처를 통계적으로 선별하기 위해 다음 네 가지 가설을 검정했습니다.

| 가설 | 검정 | p-value |
|---|---|---|
| 시즌 누적 이닝(선발 ≥170, 불펜 ≥70) 그룹별 ERA·FIP 차이 | t-검정 | p < 0.001 |
| 체감온도 30°C 이상·미만 경기 FIP 차이 | t-검정 | p < 0.001 |
| 연투 여부(휴식일 없이 등판)별 FIP 차이 | t-검정 | p = 0.005 |
| 키 180cm / 체중 90kg 그룹별 부상 발생 비율 | 카이제곱 | 키 p < 0.001, 체중 p = 0.038 |

### 5.3 피로도 지수(Fatigue Score) 설계

**피처 4종** — `NP/IP` · `3경기 변화구 구사율` · `혹사 정도(연투 여부·휴식일 수·연투 일수)` · `누적 연투 일수`.

**산출 과정**
1. RandomForest · XGBoost · LightGBM **앙상블**로 FIP를 예측.
2. SHAP으로 각 피처가 FIP 예측에 기여한 정도를 가중치로 산출.
3. 각 피처를 z-score 표준화 → 정규 CDF → 0~100 스케일링.
4. SHAP 가중치를 곱해 합산 → 최종 피로도 지수.

**가중치 적용 공식**

```
Fatigue Score = 0.490·z(NP/IP) + 0.098·z(변화구 구사율) + 0.266·z(혹사 정도) + 0.146·z(누적 연투일수)
```

NP/IP(가중치 0.490)와 혹사 정도(0.266)가 피로 형성의 두 축을 차지함을 SHAP 해석으로 확인했습니다.

### 5.4 교체 임계값 도출

회복 여부(휴식일 5일 이상 확보 가능 여부)를 분류 타깃으로 Decision Tree + GridSearchCV를 적용해 최적 분리 임계값 **72.6** 을 산출했습니다. 이 값은 피로도 분포 상위 약 **20%** 구간에 해당하며, 초과 시 교체·휴식을 자동 권고하는 운영 가이드라인을 도출합니다.

### 5.5 투수 역전점 모델링

세 그룹의 변수를 Standard Scaling 후 다중 회귀에 투입합니다.

- **외부 환경**: 누적 이동 거리, 체감온도, 구장, 국제대회·포스트시즌 경험
- **선수 기량**: ERA, WHIP, 직구 피안타율, K/BB
- **신체 조건**: 나이, 키, 몸무게, 부상 위험도

두 투수 A·B의 GS(Game Score)를 종속변수로 한 회귀선이 교차하는 피로도 값을 **역전점**으로 정의합니다. SHAP 가중치 해석 결과 ERA(가중 −0.50)·WHIP(가중 +0.45)·나이(가중 +0.50)가 역전점 산정에 가장 큰 영향을 미쳤습니다.

### 5.6 배포 (Streamlit 앱)

`app/역전점_앱.py` — 기준 날짜와 두 투수를 선택하면 최근 30일 피로도 추이와 그날의 역전점을 비교해 자동으로 *"A 기용 권장 / B 기용 고려"* 메시지를 출력합니다.

## 6. 주요 결과

### 6.1 피로도 ↔ 투수 성과 상관

| 성과 지표 | 상관계수 r | 결정계수 R² | 방향 |
|---|---|---|---|
| **WHIP** (출루 허용률) | **0.76** | **0.58** | 양 (+) |
| ERA (평균자책점) | 0.55 | 0.30 | 양 (+) |
| FIP (수비 무관 평균자책점) | 0.50 | 0.25 | 양 (+) |
| **GS** (Game Score, 경기 퍼포먼스) | **−0.50** | 0.25 | 음 (−) |

피로도가 누적될수록 안타·볼넷을 통한 주자 출루가 증가(WHIP)하고 평균자책점도 함께 상승하며, 전반적 경기력(GS)은 하락합니다. 가장 강한 상관은 WHIP(r = 0.76)으로, **피로도는 결과 통계(ERA)보다 과정 통계(출루 허용)에 먼저 반영**됨을 시사합니다.

### 6.2 교체 가이드라인

- **임계값 72.6** — Decision Tree + GridSearchCV로 도출한 회복 가능 vs 회복 불가능의 분리 지점.
- 피로도 분포 상위 약 **20%** 구간에 해당.
- 초과 시 교체·휴식을 권고하는 자동 가이드라인.

### 6.3 역전점 시뮬레이터 (Streamlit)

- 두 투수 GS 회귀선의 교차점을 역전점으로 정의 → 감독이 그날의 피로도 흐름과 역전점을 한 화면에서 비교 가능.
- 실행 화면 예시: *"백정현의 피로도 지수가 20.8 이상이면 한대인보다 GS가 나빠집니다. 현재 피로도 백정현 41.5, 한대인 48.1 — 한대인 기용이 더 효율적입니다."* (앱 출력 메시지 그대로)

## 11. 한계 및 향후 과제

- **KBO 측정 데이터의 한계** — MLB·NPB와 달리 KBO는 투구 RPM(회전수)·스핀 효율·릴리스 포인트 등 세부 데이터 수집이 충분하지 않아 피로도 지수의 고도화에 한계가 있습니다. 웨어러블 센서·고속 카메라가 도입되면 *투구 품질·궤적 정보*를 추가 피처로 반영할 수 있습니다.
- **단일 시즌 데이터** — 2025 시즌 단일 표본으로 시즌 간 변동성 검증이 불가합니다. 다년치 데이터로 확장하면 임계값 72.6의 안정성을 재검증할 수 있습니다.
- **실시간 연동 부재** — 현재 시뮬레이터는 사전 적재 데이터 기반. 경기 직전·직후 자동 업데이트되는 실시간 워크플로우는 후속 과제입니다.
- **생체 데이터 미포함** — 심박수·근육 활성도·이동 회복 속도 등 웨어러블 생체 데이터를 결합하면 개인 단위 정밀 모니터링이 가능합니다.
- **타 리그·포지션 적용** — 본 연구는 KBO 선발 투수 중심. MLB·NPB 환경 변수(구장 크기·평균 기온)와 타자·불펜·마무리 포지션별 특화 피처가 추가되면 모델 범용성이 확장됩니다.
