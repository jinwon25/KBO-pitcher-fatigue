# 노트북 안내

이 폴더는 학술제 당시의 팀 분석 과정과 현재 포트폴리오에서 정리한 전체 분석 흐름을 함께 보존합니다.

처음 보는 독자는 루트 README에서 전체 흐름을 확인한 다음 [`analysis.ipynb`](./analysis.ipynb)를 보면 됩니다. 이 노트북은 학술제 핵심 결과, 김택연 사례, 역할별 다음 등판, 시간 순서 기반 선발 모델, 2023–2024 공개 투구 단위 데이터를 하나의 흐름으로 연결합니다.

`00`~`05` 노트북은 학술제에서 실제로 수행한 데이터 가공, 피로도 모델링, 역전점 설계, 시계열 탐색, 시각화 과정을 보여 주는 팀 프로젝트 기록입니다. 파일명의 `1차`, `2차`는 당시 여러 모델 대안을 실험한 순서를 의미합니다.

학술제 당시의 세부 실험은 `00`~`05` 노트북과 발표 자료에서, 정리된 전체 흐름은 `analysis.ipynb`와 `reports/metrics.json`에서 확인할 수 있습니다.
