# 노트북 안내

처음 보는 독자는 [`analysis.ipynb`](./analysis.ipynb) 하나만 실행하면 됩니다. 정본 데이터를 불러와 데이터 계약, 점수 정의, 기술적 관계, 임계값 진단을 순서대로 재현합니다.

나머지 `00`~`05` 노트북은 학술제 당시의 탐색 과정을 보존한 기록입니다. 파일명의 `1차`, `2차`는 당시 실험 순서를 뜻하며 현재 분석의 버전이 아닙니다. 다음 이유로 대표 실행 경로에는 포함하지 않습니다.

- 로컬 중간 파일과 과거 실행 순서에 의존
- 같은 표본에서 학습과 평가를 수행한 셀 포함
- 목표변수와 설명이 다른 임계값 실험 포함
- 실행되지 않은 셀과 현재 웹 구조에서 실패할 수 있는 과거 크롤링 코드 포함

과거 노트북을 열람할 때는 결과 근거가 아니라 작업 과정 기록으로 봐 주세요. 현재 결론은 루트 README, `analysis.ipynb`, `reports/metrics.json`이 기준입니다.
