# 노트북 안내

이 폴더는 학술제 당시의 팀 분석 과정과 이후 개인 후속 검증을 함께 보존합니다.

처음 보는 독자는 루트 README에서 전체 흐름을 확인한 다음 [`analysis.ipynb`](./analysis.ipynb)를 실행하면 됩니다. 이 노트북은 후속 검증에 해당하며 정본 데이터의 계약, 점수 정의, 기술적 관계, 임계값 진단을 순서대로 재현합니다.

`00`~`05` 노트북은 학술제에서 실제로 수행한 탐색·모델링 과정을 보여 주는 팀 프로젝트 기록입니다. 파일명의 `1차`, `2차`는 당시 실험 순서를 뜻하며 현재 공개본의 버전명이 아닙니다. 수상 프로젝트의 작업 근거로 보존하되, 다음 이유로 현재 재현성 검사의 대표 실행 경로에는 포함하지 않습니다.

- 로컬 중간 파일과 과거 실행 순서에 의존
- 같은 표본에서 학습과 평가를 수행한 셀 포함
- 목표변수와 설명이 다른 임계값 실험 포함
- 실행되지 않은 셀과 현재 웹 구조에서 실패할 수 있는 과거 크롤링 코드 포함

학술제 당시의 결론과 분석 흐름은 이 노트북과 발표 자료에서, 후속 검증의 결론은 루트 README, `analysis.ipynb`, `reports/metrics.json`에서 확인할 수 있습니다.
