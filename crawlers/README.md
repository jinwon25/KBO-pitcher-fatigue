# 수집 코드 안내

이 폴더는 학술제 당시 MYKBO·스탯티즈·KBO 웹페이지에서 자료를 모으기 위해 사용한 역사적 수집 코드입니다. 현재 사이트 구조와 브라우저 환경에서의 동작을 보장하지 않으며, 정본 데이터를 처음부터 만드는 단일 자동화 파이프라인도 아닙니다.

특히 `투수_크롤링.py`의 선수 매핑은 비어 있고, 일부 스크립트는 수동 입력·브라우저 드라이버·현재 작업 디렉터리에 의존합니다. 과거 `스탯티즈_크롤링.ipynb`에서 발생한 Selenium 요소 탐색 실패 출력은 공개 노이즈와 로컬 경로 노출을 막기 위해 비웠습니다.

현재 저장소의 재현 대상은 커밋된 `data/final/fatigue_with_index.csv` 이후의 검증과 탐색입니다. 수집 코드는 출처와 작업 과정을 보여 주기 위해 보존합니다.
