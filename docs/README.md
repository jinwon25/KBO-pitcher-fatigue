# 분석 문서 안내

이 프로젝트의 질문은 투수의 투구 부담과 경기 내 변화를 교체·휴식 판단에 어떻게 활용할 수 있는가입니다. 결과 요약은 [프로젝트 README](../README.md)를 먼저 읽고, 지표와 검증 조건을 아래 순서로 확인합니다.

## 읽는 순서

1. [분석 방법과 검증 기준](METHODOLOGY.md): 피로 신호의 정의, 선발·불펜 구분, 같은 등판과 다음 등판의 차이.
2. [공개 데이터 소스 검토](PUBLIC_DATA_SOURCES.md)와 [투구 단위 데이터 안내](../data/external/README.md): 매칭 범위와 이용 조건.
3. [학술제 당시 분석 기록](ORIGINAL_PROJECT.md): 최초 문제의식과 팀 작업. 이후 확장 분석과 구분합니다.
4. [노트북 안내](../notebooks/README.md), [핵심 수치](../reports/metrics.json): 실제 분석 흐름과 저장된 결과.
5. [참고 연구](references/README.md): 연구 배경과 적용 범위.

## 먼저 이해할 용어

| 용어 | 이 프로젝트에서의 뜻 |
|---|---|
| 투구 부담(workload) | 투구수·연투·휴식 등 투수에게 누적되는 경기 부담입니다. |
| 피로도 지수 | 부담과 경기 지표를 합친 표본 내 상대 점수입니다. 생리적 피로를 직접 측정한 값이나 부상 확률이 아닙니다. |
| FIP / ERA / WHIP | 각각 수비 독립 투구 지표, 평균자책점, 이닝당 출루 허용 지표입니다. 당일 상태 설명과 미래 예측에 쓰는 시점을 구분합니다. |
| GS | Game Score. 선발 투수의 한 경기 성과를 요약하는 점수입니다. |
| RE24 / BF | 주자·아웃 상태에 따른 기대득점 변화 / 상대 타자 수입니다. 이 프로젝트의 RE24/BF는 불펜의 타자당 득점 허용 맥락을 비교합니다. |
| CSW% | 루킹 스트라이크와 헛스윙의 합이 전체 투구에서 차지하는 비율입니다. |
| 릴리스 분산도 | 공을 놓는 위치의 흔들림 정도입니다. RMS 거리로 요약하며 값이 커질수록 위치가 더 퍼집니다. |
| MAE / R² | 평균 절대 오차 / 설명력 지표입니다. 평가 대상과 시점이 같은 기준 모델과 비교합니다. |
| bootstrap / CI | 표본을 다시 뽑아 불확실성을 계산하는 방법 / 신뢰구간입니다. 투수 단위 재추출로 같은 투수 내 의존성을 고려합니다. |
| SHAP | 모델 출력에 대한 변수 기여를 설명하는 방법입니다. 변수의 인과효과를 뜻하지 않습니다. |

## 해석 기준

`72.6`은 추가 점검 후보선입니다. 당일 성과와의 관계를 미래 성과의 예측력으로 바꾸어 읽지 않습니다. 다음 등판 결과는 시간 순서 검증과 신뢰구간을 함께 확인합니다.
