# 공개 데이터 소스 검토

검토일: 2026-09-16

목표는 피로도 지수를 박스스코어 결과뿐 아니라 구속 유지, 구위·제구 과정, 등판 맥락으로 확장할 수 있는 공개 자료를 찾는 것이었습니다. 출처의 세밀도, 기간 중첩, 라이선스, 재현 가능성을 함께 평가했습니다.

## 채택한 데이터

### KBO Play-by-Play 2023–2026

- 데이터 카드: [`slothman3878/kbo_playbyplay`](https://huggingface.co/datasets/slothman3878/kbo_playbyplay)
- 생성 코드와 스키마: [`kbo_pbp_naver_sports`](https://github.com/slothman3878/kbo_pbp_naver_sports)
- 라이선스: CC BY 4.0
- 단위: 1행 1구
- 주요 컬럼: 투수·타자, 구종, 구속, 투구 위치, 볼카운트, 주자·아웃, 득점 상태
- 장점: 현재 정본과 2023–2024년이 겹치며 선수명·날짜·팀으로 97.5% 연결
- 적용: 구속 유지, CSW%, 존 통과율, 초구 스트라이크율, 접전 후반 투구 비중

데이터셋은 원문 중계 텍스트를 제외한 구조화 파생 기록이며, 데이터 카드에도 원 출처의 별도 권리와 약관을 준수해야 한다고 명시돼 있습니다. 저장소에는 고정 revision에서 만든 작은 등판 단위 파생 데이터만 포함했습니다.

## 데이터 결합 원칙

1. 홈·원정과 이닝 공수 정보로 투수 소속팀을 복원하고 `(선수, 날짜, 팀)`을 결합 키로 사용합니다. 동명이인 투수 기록은 합치지 않습니다.
2. 양쪽 투구수를 비교해 매칭 정확도를 확인합니다.
3. 원본 버전과 파일 해시를 고정합니다.
4. 원문 데이터 전체를 재배포하지 않고 분석에 필요한 파생 지표만 저장합니다.
5. 결과 지표와 과정 지표를 분리합니다. ERA·WHIP·FIP는 경기 결과, CSW·존 통과율·구속 유지는 과정 신호로 해석합니다.
6. 다음 등판 분석은 같은 선수·같은 보직·같은 시즌이며 30일 이내인 경우로 제한합니다.

## 추가 확보 우선순위

1. 공식 부상자 명단과 엔트리 제외 사유
2. 트레이닝 데이터 또는 회복 상태처럼 실제 피로에 가까운 라벨
3. 릴리스 포인트·구종별 수직/수평 무브먼트의 경기 내 변화
4. 구원 등판 시 gmLI와 승계주자 득점 방지 지표

공개 데이터만으로 생리적 피로를 직접 관측할 수는 없습니다. 따라서 현재 확장은 “피로 진단”이 아니라 workload와 투구 과정의 변화를 함께 보는 의사결정 지원 분석으로 범위를 유지합니다.
