# 학술제 분석 기록

이 문서는 제4회 중앙대학교 데이터 분석 학회 DArt-B 학술제에서 발표하고 대상을 수상한 팀 프로젝트의 문제의식, 분석 흐름, 당시 결과를 보존합니다. 이후 개인 후속 검증에서 해석이나 활용 수준이 달라진 내용은 별도로 표시합니다.

## 프로젝트 배경

팀은 투수 교체가 감독의 경험과 직관에 크게 의존하고, 특정 투수의 반복 기용이 피로 누적과 경기력 저하로 이어질 수 있다는 문제에서 출발했습니다. 목표는 다음 세 질문에 답하는 것이었습니다.

1. 투수 피로도에 영향을 미치는 변수는 무엇인가?
2. 피로 누적은 어떤 상황에서 자주 나타나는가?
3. 피로 신호를 수치화해 교체 판단을 보조할 수 있는가?

## 팀과 역할

- 소속: 중앙대학교 데이터 분석 학회 DArt-B 5기
- 팀명: 최강이세용
- 팀원: 강경희, 강세범, 이정연, 조용호, 최진원
- 최진원 역할: EDA, 데이터 전처리, 모델링, 결과 해석 및 시각화
- 개인 기여도: 40%
- 결과: 제4회 DArt-B 학술제 대상

## 데이터 수집과 통합

학술제 당시 다음 출처를 조합했습니다.

| 범주 | 출처와 변수 |
|---|---|
| 경기별 투구 기록 | MYKBO 기반 이닝, 투구수, 실점, 피안타, 볼넷 등 |
| 시즌·고급 지표 | 스탯티즈 기반 ERA, FIP, WHIP, K/BB, 구종 관련 지표 |
| 선수와 일정 | KBO 공식 사이트 기반 선수, 소속팀, 일정 정보 |
| 외부 환경 | 기상 정보, 구장, 이동거리 |
| 누적 부담 | 연투 여부, 휴식일, 누적 이닝, 국제대회·포스트시즌 경험 |

수집 코드와 병합 노트북은 `crawlers/`, 원본과 중간 산출물은 `data/raw/`, `data/processed/`에 보존돼 있습니다. 현재 사이트 구조에서는 크롤러의 재실행을 보장하지 않습니다.

## 탐색과 가설 검정

발표에서는 다음 탐색 결과를 피처 선정 근거로 사용했습니다.

| 당시 가설 | 당시 보고 결과 |
|---|---|
| 시즌 누적 이닝 그룹별 ERA·FIP 차이 | p < 0.001 |
| 체감온도 30°C 이상·미만 경기 FIP 차이 | p < 0.001 |
| 연투 여부에 따른 FIP 차이 | p = 0.005 |
| 키·체중 그룹별 부상 발생 비율 차이 | 키 p < 0.001, 체중 p = 0.038 |

위 수치는 학술제 발표 당시의 분석 결과입니다. 후속 공개본에서는 표본 독립성, 다중 검정, 부상 라벨 정의를 다시 확인할 수 있는 단일 실행 경로가 남아 있지 않아 현재의 확증 결과로 재보고하지 않습니다.

## 피로도 지수 설계

학술제 분석에서는 다음 계열의 변수를 중심으로 피로 신호를 구성했습니다.

- NP/IP
- 최근 3경기 구종 구사율
- 연투와 휴식일을 결합한 혹사 정도
- 누적 연투 일수

RandomForest, XGBoost, LightGBM으로 경기력 지표를 모델링하고 SHAP 중요도를 가중치 후보로 활용했습니다. 발표 자료에서는 아래 형태의 가중 결합식을 제시했습니다.

```text
Fatigue Score
= 0.490 × z(NP/IP)
+ 0.098 × z(변화구 구사율)
+ 0.266 × z(혹사 정도)
+ 0.146 × z(누적 연투 일수)
```

최종 CSV에는 원점수 `피로도지수`와 0–100 값 `피로도지수_점수`가 저장돼 있습니다. 개인 후속 검증에서 0–100 값은 원점수의 전체 표본 백분위임을 확인했습니다.

## 발표 결과와 의사결정 아이디어

### 경기력 관계

발표에서는 피로도 증가와 WHIP·ERA·FIP 상승, GS 하락의 관계를 보고했습니다.

| 당시 발표 지표 | 상관계수 r | 결정계수 R² |
|---|---:|---:|
| WHIP | 0.76 | 0.58 |
| ERA | 0.55 | 0.30 |
| FIP | 0.50 | 0.25 |
| GS | -0.50 | 0.25 |

이 결과를 바탕으로 피로 지수가 투수의 컨디션 저하 신호로 활용될 가능성을 제시했습니다.

후속 검증에서도 관계의 방향은 확인됐지만, 동일 경기 데이터로 점수를 개발하고 평가한 순환성이 있어 미래 예측력으로 해석하지 않습니다.

### 교체 임계값

발표에서는 Decision Tree와 GridSearchCV를 활용해 피로도 `72.6`을 교체·휴식 검토 후보 기준으로 제안했습니다. 이는 학술제의 핵심 의사결정 아이디어였습니다.

후속 검증에서는 노트북 설명과 실제 타깃, 저장된 원점수 임계값과 72.6의 연결을 완전히 재현하지 못했습니다. 따라서 원 결과는 당시의 탐색적 제안으로 보존하고, 현재 앱의 자동 규칙에서는 제외했습니다.

### 역전점 시뮬레이터

두 투수의 외부 환경, 기량, 신체 조건, 피로도에 따른 경기력 선이 교차하는 지점을 “역전점”으로 정의하고 Streamlit 앱으로 구현했습니다. 이는 복잡한 분석 결과를 실제 의사결정 화면으로 연결하려는 시도였습니다.

후속 코드 점검에서 실제 앱이 문서의 GS가 아닌 WHIP를 목표로 사용했고, WHIP가 입력 변수에도 포함된 목표 누수가 확인됐습니다. 현재 앱은 자동 비교 모델을 제거했지만, 투수의 workload와 컨디션을 한 화면에서 비교한다는 제품 방향은 유지합니다.

## 후속 작업과의 관계

개인 후속 작업은 학술제 결과를 부정하기 위한 것이 아니라, 탐색적 분석을 실제 의사결정 도구로 발전시키기 위해 필요한 검증 조건을 구체화한 과정입니다.

- 원 프로젝트가 보여 주는 역량: 문제 정의, 다양한 데이터 결합, 피처 설계, 모델 해석, 앱 구현, 팀 발표
- 후속 작업이 보여 주는 역량: 재현성 감사, 목표 누수 발견, 지표 정의 교정, 검증 수준 조정, 테스트·CI 구축

두 작업은 하나의 분석이 성숙해 가는 연속된 기록입니다.
