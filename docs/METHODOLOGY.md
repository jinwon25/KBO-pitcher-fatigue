# 방법론과 검증 노트

이 문서는 공개 저장소의 코드와 커밋된 데이터만으로 재현한 감사 결과입니다. 원 발표 자료의 서술보다 실행 가능한 산출물을 우선합니다.

## 분석 질문

1. 최종 데이터와 문서의 기간·대상·행 수가 일치하는가?
2. `피로도지수_점수`는 어떤 값인가?
3. 성과 지표와의 관계가 저장된 데이터에서 재현되는가?
4. 기존의 교체 임계값과 자동 추천이 독립적인 예측 근거를 갖는가?

## 정본과 데이터 계약

정본은 [`../data/final/fatigue_with_index.csv`](../data/final/fatigue_with_index.csv)입니다.

- 17,528행, 80열
- 163명, 2020-05-05~2024-10-01
- 선발 3,507행, 불펜 14,021행
- `(선수, 날짜)` 중복 0건
- `부상위험도` 결측률 58.67%

`data/raw/mykbo_2025/`는 별도의 수집 산출물이며 현재 정본과 연결된 완결 파이프라인이 없습니다. 따라서 2025년 데이터라는 과거 설명을 현재 분석 범위에 사용하지 않습니다.

## 점수 정의

`피로도지수`는 과거 모델링 과정에서 만들어져 최종 CSV에 저장된 원점수입니다. `피로도지수_점수`는 아래 식과 정확히 일치합니다.

```python
df["피로도지수"].rank(method="average", pct=True) * 100
```

따라서 0–100 값은 확률이나 절대 척도가 아닙니다. 데이터가 추가되거나 비교 모집단이 바뀌면 같은 원점수의 백분위도 달라집니다.

## 기술적 관계

`피로도지수`와 같은 행의 지표에 대해 피어슨 상관을 계산합니다. 선수 간 평균 수준 차이를 제거하기 위해 선수별 평균을 뺀 within-player 상관도 함께 저장합니다.

| 지표 | 전체 행 r | 선수 내 r |
|---|---:|---:|
| WHIP | 0.8338 | 0.8365 |
| ERA | 0.6374 | 0.6403 |
| FIP | 0.4822 | 0.4825 |
| GS | -0.3890 | -0.4507 |

이 값은 같은 경기의 동시 상관입니다. 원 노트북이 경기 결과에서 모델 가중치를 학습하고 동일 표본에서 점수와 결과의 관계를 다시 평가했으므로, 미래 예측 성능으로 보고하지 않습니다.

## 임계값 검증

원 노트북의 설명과 실제 코드는 서로 달랐습니다.

- 설명: `회복실패여부`를 분류해 임계값을 정한다.
- 실제 Decision Tree 셀: `부상위험도`가 결측이 아니고 0보다 크면 1인 `부상여부`를 타깃으로 사용한다.
- 저장된 출력: 원점수 임계값 `3.7319897`.
- 과거 README 주장: 0–100 점수 임계값 `72.6`.

저장된 데이터 전체에서 순위 기반 ROC AUC를 재계산한 결과는 다음과 같습니다.

| 타깃 | ROC AUC |
|---|---:|
| `회복실패여부` | 0.5143 |
| 과거 `부상여부` 대리 라벨 | 0.5079 |

두 값은 무작위 기준인 0.5에 가깝습니다. 반복 등판한 동일 선수가 여러 fold에 들어가는 무작위 교차검증 문제까지 고려하면, 현재 자료로 안전한 교체 임계값을 주장할 수 없습니다.

## 기존 앱의 목표 누수

기존 앱은 다음 순서로 동작했습니다.

1. ERA, WHIP, 직구 피안타율로 `선수기량변수`를 생성
2. 이 변수를 입력으로 사용
3. WHIP를 종속변수로 선형회귀
4. 전체 데이터에 즉석 적합한 계수로 두 투수의 역전점을 계산

WHIP가 입력과 목표에 동시에 들어가는 직접 누수입니다. 문서에는 GS 예측이라고 적혀 있어 구현과 설명도 일치하지 않았습니다. 현재 앱은 모델 적합과 자동 추천을 제거했습니다.

## 재현 범위

완전 재현되는 범위:

- 정본 로딩, 타입 변환, 데이터 계약 검사
- 점수 백분위 관계
- 상관, 10분위 요약, AUC 진단
- README 그림과 표
- 대표 노트북과 모니터링 앱

완전 재현되지 않는 범위:

- 외부 사이트의 과거 화면에 의존한 크롤링
- 최종 `피로도지수`를 처음부터 만드는 하나의 확정된 학습 파이프라인
- 72.6 교체 임계값
- 실제 부상·회복 결과에 대한 외부 검증

## 권장 후속 연구 설계

1. 피로의 조작적 정의와 예측 시점을 먼저 고정한다.
2. 예측 시점 이전에 알 수 있는 투구수, 이닝, 휴식일, 연투 등 workload-only 피처만 사용한다.
3. 미래 경기 성과 또는 검증된 부상·회복 라벨을 타깃으로 둔다.
4. 2020–2023년 학습, 2024년 최종 테스트처럼 시간 순서를 보존한다.
5. 동일 선수의 반복 측정을 고려해 선수 단위 그룹 검증과 bootstrap 신뢰구간을 보고한다.
6. 임계값은 비용 함수, 민감도·특이도, calibration을 함께 제시하고 외부 시즌에서 재검증한다.
