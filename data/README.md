## 현재 정본

현재 분석과 앱은 `final/fatigue_with_index.csv` 하나만 읽습니다.

- 17,528행, 80열
- 2020-05-05~2024-10-01
- 163명
- `(선수, 날짜)` 유일 키
- UTF-8 CSV

`final/legacy_최종.csv`는 세 개의 파생 컬럼을 통합한 작업 이력을 보존하는 파일이며, 현재 분석은 통합이 완료된 정본을 사용합니다.

## 원본과 중간 산출물

- `raw/`: 2025년 별도 수집 파일과 과거 크롤링 결과
- `processed/`: 병합 단계의 중간 CSV
- `final/`: 현재 분석 정본과 legacy 파일

`raw/mykbo_2025/2025년_mykbo.csv`는 후속 시즌 확장을 위해 별도로 수집한 자료입니다. 현재 공개 분석은 발표자료와 정본이 공통으로 다루는 2020–2024년을 기준으로 하며, 2025년 연결은 스키마 정합화 후 진행할 수 있습니다.

중간 파일은 수집·병합 단계별 산출물을 보존합니다. 현재 정본의 `(선수, 날짜)` 키는 중복이 없으며, `scripts/validate_repo.py`와 테스트가 이를 자동으로 검사합니다.

## 알려진 결측

정본의 `부상위험도`는 58.7%가 결측입니다. 후속 분석에서는 이 값을 별도 정보 상태로 유지하며, 실제 부상 발생 라벨이 확보되면 외부 검증에 활용할 예정입니다.
