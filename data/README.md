# 데이터 디렉터리 안내

## 현재 정본

현재 분석과 앱은 `final/fatigue_with_index.csv` 하나만 읽습니다.

- 17,528행, 80열
- 2020-05-05~2024-10-01
- 163명
- `(선수, 날짜)` 유일 키
- UTF-8 CSV

`final/legacy_최종.csv`는 세 개의 파생 컬럼을 합치기 전후 작업을 추적하기 위해 남긴 과거 파일입니다. 신규 분석에서는 사용하지 않습니다.

## 원본과 중간 산출물

- `raw/`: 2025년 별도 수집 파일과 과거 크롤링 결과
- `processed/`: 병합 단계의 중간 CSV
- `final/`: 현재 분석 정본과 legacy 파일

`raw/mykbo_2025/2025년_mykbo.csv`는 정본과 기간·스키마가 다른 별도 자료입니다. 저장소에는 raw에서 final까지 모든 변환을 한 번에 재실행하는 완결된 파이프라인이 없으므로, 두 데이터를 하나의 2025년 분석으로 해석하지 않습니다.

일부 중간 파일에는 원천 수집 과정에서 생긴 중복 행이 남아 있습니다. 현재 정본의 `(선수, 날짜)` 키는 중복이 없으며, `scripts/validate_repo.py`와 테스트가 이를 검사합니다.

## 알려진 결측

정본의 `부상위험도`는 58.7%가 결측입니다. 실제 부상 발생 여부를 나타내는 검증 라벨이 아니므로 결측을 0으로 대체하거나 부상 확률로 해석하지 않습니다.
