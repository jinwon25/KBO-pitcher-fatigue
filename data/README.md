- 17,528행, 80열
- 2020-05-05~2024-10-01
- 163명
- `(선수, 날짜)` 유일 키

`final/legacy_최종.csv`는 세 개의 파생 컬럼을 통합한 작업 이력을 보존하는 파일이며, 현재 분석은 통합이 완료된 정본을 사용합니다.

## 원본과 중간 산출물

- `raw/`: 2025년 별도 수집 파일과 과거 크롤링 결과
- `processed/`: 병합 단계의 중간 CSV
- `final/`: 현재 분석 정본과 legacy 파일
- `external/`: 라이선스가 확인된 공개 데이터의 등판 단위 파생 자료

`raw/mykbo_2025/2025년_mykbo.csv`는 후속 시즌 확장을 위해 별도로 수집한 자료입니다. 현재 파일은 2025-03-23~2025-07-10의 2,580행·99명을 담은 **부분 시즌 스냅샷**입니다. `(Name, Date, Team)` 중복 13행은 5월 10일·17일 더블헤더 등판으로 보이지만 경기 ID가 없어 안전한 일대일 결합이 불가능합니다. 부상 표도 11건이므로 현재 공개 분석은 2020–2024 정본을 기준으로 유지하며, 2025 완전 시즌·경기 ID·라벨을 확보한 뒤 외부 검증을 진행합니다.

중간 파일은 수집·병합 단계별 산출물을 보존합니다. 현재 정본의 `(선수, 날짜)` 키는 중복이 없으며, `scripts/validate_repo.py`와 테스트가 이를 자동으로 검사합니다.

`external/pbp_appearance_2023_2024.csv`는 CC BY 4.0 KBO 투구 단위 공개 자료를 정본과 연결한 파생 데이터입니다. 출처, 고정 revision, 해시, 생성 명령은 [`external/README.md`](./external/README.md)에 정리했습니다.

## 알려진 결측

정본의 `부상위험도`는 58.7%가 결측입니다. 후속 분석에서는 이 값을 별도 정보 상태로 유지하며, 실제 부상 발생 라벨이 확보되면 외부 검증에 활용할 예정입니다.
